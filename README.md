# Bihar — बिहार सांस्कृतिक एवं पर्यटन पोर्टल

बिहार की समृद्ध ऐतिहासिक विरासत, 38 जिलों की प्रशासनिक व भौगोलिक पहचान, लोकसंस्कृति, पर्व-त्योहार, पर्यटन और सामाजिक-आर्थिक परिदृश्य का व्यापक एवं आधुनिक वेब पोर्टल।

## 🌟 प्रमुख विशेषताएँ (Key Features)

- **38 जिले (All 38 Districts)**: हर जिले का इतिहास, भूगोल, संस्कृति, प्रशासन, प्रमुख स्थल और जनसांख्यिकी।
- **सांस्कृतिक धरोहर (Cultural Heritage)**: मिथिला चित्रकला, बिदेसिया, बिरहा, चैता, सोहर और लोक नाट्य परंपराएँ।
- **धार्मिक एवं ऐतिहासिक पर्यटन (Tourism & Circuits)**: बौद्ध, जैन, सूफी, सिख और हिंदू तीर्थ स्थलों का प्रामाणिक यात्रा विवरण।
- **भूगोल एवं जल तंत्र (Geography & Water Systems)**: गंगा, सोन, गंडक, कोसी आदि नदियों का तंत्र और कृषि परिदृश्य।
- **आधुनिक एवं सुलभ इंटरफेस (Responsive & Accessible UI)**: द्विभाषी (हिंदी/अंग्रेजी), मोबाइल-फ्रेंडली और उत्पादन स्तर का डिज़ाइन।

## 🛠️ तकनीकी विवरण (Tech Stack)

- **Frontend**: React 18, React Router v6
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Styling**: Vanilla CSS (Custom Design System)

## 🚀 शुरुआत कैसे करें (Getting Started)

### 1. Dependencies इंस्टॉल करें
```bash
npm install
```

### 2. Development Server शुरू करें
```bash
npm run dev
```

### 3. Production Build तैयार करें
```bash
npm run build
```

### 4. Data Validation Scripts
```bash
npm run validate:districts
npm run validate:tourism
npm run validate:culture-all
```
